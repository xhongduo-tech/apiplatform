# Support

Community support is provided through the repository issue tracker on a
best-effort basis. Before opening a support question:

1. Read the installation, troubleshooting, and upgrade sections in `README.md`.
2. Search open and closed issues.
3. Reproduce on the latest supported release with fictional data.
4. Use the **Support question** issue form and include the deployment method,
   version, safe logs, and steps already attempted.

Public support is not suitable for vulnerabilities, secrets, API keys, database
exports, user prompts/responses, personal information, or private network data.
Use the private process in `SECURITY.md` for security concerns. Project
maintainers do not provide a guaranteed response time or individual deployment
consulting through public issues.
